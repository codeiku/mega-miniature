# Essential Development Commands

## Development Workflow
- **`npm run dev`** - Start development server with hot reload
- **`npm run build`** - Build for production
- **`npm run preview`** - Preview production build locally

## Code Quality
- **`npm run lint`** - Run ESLint to check and fix code style issues
- **`npm run format`** - Format code with Prettier

## System Commands (macOS)
- **`ls`** - List files and directories
- **`cd <directory>`** - Change directory
- **`grep <pattern> <files>`** - Search for text patterns
- **`find <path> -name <pattern>`** - Find files by name
- **`git status`** - Check git repository status
- **`git add .`** - Stage all changes
- **`git commit -m "message"`** - Commit changes
- **`git push`** - Push to remote repository

## Package Management
- **`npm install`** - Install dependencies
- **`npm install <package>`** - Install new package
- **`npm uninstall <package>`** - Remove package
- **`npm update`** - Update dependencies

## File Operations
- **`cat <file>`** - Display file contents
- **`head <file>`** - Show first lines of file
- **`tail <file>`** - Show last lines of file
- **`cp <source> <dest>`** - Copy files
- **`mv <source> <dest>`** - Move/rename files
- **`rm <file>`** - Remove files

## Process Management
- **`ps aux`** - List running processes
- **`kill <pid>`** - Terminate process by ID
- **`killall <name>`** - Terminate processes by name

## Development Server
- **Default Port**: 5173 (Vite development server)
- **Hot Reload**: Automatic when files change
- **Network Access**: Available on local network
